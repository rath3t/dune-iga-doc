template<int dim_, int dimworld_, typename ScalarType = double>
ConnectionResult Dune::IGA::GeometryKernel::NURBSPatch< dim_, dimworld_, ScalarType >::isConnectedAtBoundary ( int  boundary,
double  tol = 1e-8 
) const
inline

Check if the patch is connected at the given boundary.

This function checks if the patch is connected at the specified boundary. The boundary index is determined by the vertex numbering for lines, the edge numbering for quadrilaterals, and the face numbering for cubes. For more details, refer to DUNE Book Chapter 5.5.

Parameters
boundaryThe index of the boundary to check (vertex for lines, edge for quadrilaterals, face for cubes).
tolAbsolute tolerance for comparing control points. Default is 1e-8.
Returns
A ConnectionResult object indicating whether the patch is connected at the specified boundary. The isConnected member is true if the patch is connected, and the boundary member is the index of the adjacent boundary if connected, or -1 if not connected.
Template Parameters
boundaryThe boundary index to check.
tolAbsolute tolerance for comparing control points. Default is 1e-8.
Exceptions
Dune::NotImplementedIf the dimension is greater than 3 (higher dimensions not implemented yet).
